Mainnet is not recorded as deployed. The current revision does not attest live testnet state.

Use the [public deployment registry](https://github.com/CoverFI-space/coverfi-contracts/blob/main/contracts.json). It preserves historical local IDs as unverified records. The former coverfi-space/coverfi registry URL is not used.

The public [contracts workspace](https://github.com/CoverFI-space/coverfi-contracts) has seven crates. The proposed funding release is narrower; see [funding scope](/funding-scope). Do not assume current source implements historical deployed IDs.

## Reproduce source checks

From the contracts repository:

```sh
cargo test --workspace --locked
cargo build --workspace --release --target wasm32v1-none --locked
```

These are commands to run, not claims that they passed. Publish the current CI run, toolchain and commit. Historical test totals are not reused as current evidence.

## Release evidence required

Publish source commit, WASM hashes, network, asset issuer/token contract, deployment and initialization transaction hashes, engine/vault references, admin and publisher policy, reserve seed/balances and verification ledger/time. A new registry entry is active only after quote, creation, expiry settlement, positive claim, no-payout exit and principal withdrawal pass against that release.

The proposed pilot must specify payout denomination and conversion during depeg. Simulation outcomes must be labeled. Grants, LP commitments, testnet seed and real capital are separate accounting categories. Missing expiry observations and privileged historical price publication require explicit policies and tests.

No new mainnet or testnet deployment was performed as part of this documentation revision. No independent audit is claimed.
